The Basic Languange of the Web: HTML

Posted by Laura Jones on Monday, June 21st 2007

All modern websites and web applications are built using three fundamental fundamental technologies: HTML, CSS and JavaScript. These are the languages of the web. In this post, let's focus on HTML. We will learn what HTML is all about, and why you too should learn it.

Learning HTML

HTML stands for HyperText MarkupLanguage. It's a markup language that web developers use to structure and describe the content of a webpage (not a programming language). HTML consists of elements that describe different types of content: paragraphs, links, headings, images, video, etc. Web browsers understand HTML and render HTML code as websites.
